# Reference Links

This repository stores only code and this reference list. Large files stay on
Google Drive. Do not commit PDF, DOCX, dataset, ontology, archive, or installer
files to Git.

## Sources

| Source | What it contains | How to use it |
| --- | --- | --- |
| [Vietnamese Legal QA and Vi-LexOnto-RAG](https://drive.google.com/drive/folders/1kJygg-x8It__w5Gw6z6MJSv-EXKPb5eh) | 95 files. They include research papers about Vietnamese Legal QA, Legal RAG, ontology, and legal reasoning. The folder also has research plans, the VLSP 2025 LegalSLM public test, and a ViLQA code copy. Some PDF files are duplicates. | Use it for literature review, benchmark selection, system design, and evaluation ideas. |
| [Ontology and RAG learning materials](https://drive.google.com/drive/folders/13-ZKz_oxShnnsWxvnwZwW5z31fAK8AzR) | 67 learning files about RDF, RDFS, OWL, Protege, SPARQL, Fuseki, GraphDB, SHACL, SWRL, and Ontology RAG. It also has exercises, projects, and slides. | Use it to learn the main concepts and tools. It is not system input data. |
| [Tools and example knowledge base](https://drive.google.com/drive/folders/1gwcpv3g17vir9l_pMADe2_vePsqJknWP) | Installers for Fuseki, GraphDB, and Protege. It also has `education_knowledge_base.ttl` and two PDF guides. | Use it for tool practice and knowledge graph tests. Download new tool versions from official websites when possible. |
| [Road traffic legal documents](https://drive.google.com/drive/folders/1RhVMqDr98r5IBqArSrzUYBvoNZTjtLxE) | 40 DOCX files. They include laws, decrees, circulars, consolidated documents, and a source guide. | Use it as the source legal corpus for the road traffic domain. Check the document version and legal validity before use. |
| [Traffic Law Knowledge Base V1](https://drive.google.com/drive/folders/1uMA9Zu1IDwmoVdLhc_C9gvYvJta_1vcW) | Ontology TTL files, SHACL shapes, competency questions, SPARQL queries, a README, design documents, and a ZIP package. | Use it as a reference or starting point for the road traffic ontology. |
